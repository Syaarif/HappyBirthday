# Birthday Surprise Website

Website ucapan ulang tahun statis menggunakan HTML, CSS, dan JavaScript.

## Jalankan lokal
- Buka folder ini di VS Code.
- Buka `index.html` dengan ekstensi Live Server, atau klik dua kali file `index.html`.
- Musik berfungsi jika `assets/music.mp3` tersedia.

## Personalisasi
1. Edit `birthdayDate` di bagian atas `script.js` dengan tanggal yang benar, misalnya `2026-11-08T00:00:00+07:00`.
2. Edit surat dan caption foto di `index.html`.
3. Tambahkan foto milikmu ke folder `assets` bernama `photo1.jpg`, `photo2.jpg`, dan `photo3.jpg`.
4. Tambahkan audio yang kamu punya izin untuk gunakan sebagai `assets/music.mp3`.

## Publikasi gratis lewat GitHub Pages
1. Buat repositori baru bernama `birthday-surprise` di GitHub. Untuk GitHub Free, gunakan repositori public.
2. Upload file dan folder proyek ini ke repositori.
3. Buka **Settings > Pages**.
4. Di bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu deployment selesai. Alamat website akan ditampilkan di halaman Pages, biasanya `https://USERNAME.github.io/birthday-surprise/`.
7. Tes link di HP sebelum dikirim.

## Catatan
- Jangan masukkan informasi pribadi sensitif; website di repositori public dapat dilihat siapa saja.
- Browser biasanya memblokir autoplay musik, jadi pengunjung perlu menekan tombol Putar musik.
- Hitung mundur memakai tanggal di `script.js` dan waktu perangkat pengunjung.
